在决定建站方案之前，我在 WordPress 和静态生成器之间犹豫了很久。

## WordPress 的优点

后台完善，写文章方便，插件生态成熟，评论、搜索、SEO 都是现成的。很多优秀的个人博客就是这么跑起来的。

## 但它的代价也明显

- 需要一台 VPS，或者至少一个 PHP 空间
- 要定期更新核心、主题和插件
- 数据库要备份，安全要操心
- 动态页面意味着更慢的首屏速度

## 静态生成器

对我来说，写作本身就是编辑器里写 Markdown，后台并不是刚需。静态站点生成器把这一步推到了构建时：

```bash
npm run build   # 生成纯 HTML
# 把产物推到 Cloudflare Pages，完事
```

结果是一个**没有服务器**的站点：全球 CDN 分发，HTTPS 自动配置，几乎没有运维成本。

当然也有短板——没有内置评论。不过可以用 giscus、Waline 之类的第三方方案挂在页面上，或者干脆让读者写邮件来。对一个个人博客来说，这并不是大问题。
